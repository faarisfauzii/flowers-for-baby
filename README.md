# For Amira ❀

A page made only for her. When she opens the link, a bouquet of real flowers (rose, sunflower, tulip, daisy, lily, hydrangea) grows and blooms, all made from the letters of "babyamira", with a note from Faris.

Plain HTML, CSS and JavaScript. Files: `index.html`, `style.css`, `app.js`.

To change the note, edit the text inside `<section class="card">` in `index.html`.

Publish: GitHub Pages → Settings → Pages → Deploy from a branch → `main` / root.
